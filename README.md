## `03` — Featured Projects

### 01. YouTube Content Performance Analytics
**Python · Pandas · YouTube Data API v3 · SQL · Power BI**

**Objective:** Investigate which content characteristics are associated with stronger video reach and audience engagement.

- **Data acquisition & quality:** Retrieved approximately 2,400 raw video records using the YouTube Data API v3, then cleaned and deduplicated the dataset to retain **2,092 unique videos**. Used Pandas and validation rules to prepare the data for reliable analysis.
- **Comparative SQL analysis:** Queried short-form versus long-form content and compared video duration, views, and engagement patterns to investigate which formats correlate with stronger performance.
- **Dashboard & insights:** Developed an interactive Power BI dashboard to explore top-performing videos and duration-versus-views trends, helping content creators and marketers investigate performance patterns.

### 02. Retail Sales & Customer Analytics System
**MySQL · Excel · Python · Power BI**

**Objective:** Build a structured retail analytics solution to examine sales performance, product contribution, regional profitability, and customer segments.

- **Data modeling & SQL engineering:** Designed a **Star Schema** to organize retail data and wrote **100+ SQL queries** using Joins, CTEs, Window Functions, Views, and Subqueries to answer sales-, customer-, and product-level questions.
- **Data preparation:** Cleaned and validated raw sales records to improve consistency and prepare reliable inputs for reporting and analysis.
- **Business performance analysis:** Built interactive dashboards using Power Query and DAX to examine regional profitability, sales patterns, and high-performing customer segments.
- **Analytical value:** Connected transaction-level data with summarized KPIs to make comparisons across products, regions, and customer groups easier.

### 03. IPL Performance Analytics Dashboard
**MySQL · Python · Pandas · SQLAlchemy · Power BI**

**Objective:** Analyze ball-by-ball IPL data to compare team performance, batting contributions, and bowling trends across seasons.

- **Large-scale data processing:** Processed **280,000+ ball-by-ball records** using Python, Pandas, and SQLAlchemy to prepare match-level data for structured analysis.
- **SQL data modeling:** Organized analytical data using a Star Schema and created SQL Views to support repeatable queries and comparisons across IPL seasons.
- **Performance analysis:** Investigated team, batting, and bowling trends to enable season-wise and player-level comparisons.
- **Interactive reporting:** Built a KPI-driven Power BI dashboard that brings key performance indicators and comparative views together for faster exploration of teams and players.
